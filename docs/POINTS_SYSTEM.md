# 🪙 Экономика и алгоритм начисления коинов (Eco Points) в Bindy

> **Версия:** 2.2  
> **Статус:** Production  
> **Технический стек:** FastAPI, SQLite WAL, Gemma 4 Vision (Alem AI), React PWA  

---

## 1. 🌿 Концепция и цель экономики

**Eco Points (Коины Bindy)** — внутренняя система мотивации и геймификации пользователей за оцифровку городской инфраструктуры раздельного сбора мусора и очистку общественных пространств.

Пользователи получают коины за:
1. **Картирование урн и контейнеров** для вторсырья (пластик, стекло, бумага, органика, смешанные отходы).
2. **Фиксацию несанкционированных свалок** мусора для муниципальных служб и волонтёров.
3. **Ежедневную активность** (Day Streak).

Накопленные коины открывают доступ к скидкам и бонусам у эко-партнёров проекта в **Coin Shop**, а также определяют позицию в общем рейтинге (**Leaderboard**).

## 2. 📊 Шкала начисления коинов (Tier List)

Количество начисляемых баллов зависит от **размера объекта**, его **редкости/ценности** для городской среды и **уверенности нейросети** при проверке фото.

| Категория | Внутренний ID (`binSize` / `category`) | Описание объекта | Диапазон коинов | Логика ценности |
| :--- | :--- | :--- | :---: | :--- |
| **Уличная урна** | `street` | Обычная маленькая урна на столбе, тротуаре или в парке | **3 – 4** | Самый частый объект городской среды. Базовая награда. |
| **Колёсный бак** | `wheel` | Средний передвижной пластиковый/металлический контейнер (120–240 л) | **4 – 5** | Требует поиска во дворах или у заведений. Повышенная вместимость. |
| **Большой контейнер** | `large` | Крупногабаритный контейнер / мусорная площадка (0.75 – 1.1 м³) | **5 – 6** | Ключевая инфраструктурная точка для сортировки и утилизации. |
| **Свалка / Гора мусора** | `trash` | Масштабное несанкционированное скопление отходов на улице/природе | **8** *(фиксированно)* | Высший приоритет — устранение экологической проблемы. |

## 3. 🧠 Алгоритм проверки и расчёта через AI (Gemma 4)

Каждая фотография, загруженная пользователем через камеру, отправляется на бэкенд и верифицируется моделью компьютерного зрения **Gemma 4 Vision** (через Alem AI).

### 3.1. Этапы валидации фото:
1. **Проверка категории:** нейросеть классифицирует объект как `bin` (урна/контейнер) или `trash` (мусорная куча).
2. **Отсечение ложных объектов:**
   - ❌ Домашние и офисные вёдра отсекаются (`_looks_indoor_bin` отклоняет запрос).
   - ❌ Единичные мелкие фантики, окурки или коробки отклоняются (требуется скопление `massive`).
   - ❌ Любые посторонние фото (стены, селфи, асфальт) отклоняются по минимальному порогу уверенности (`MIN_CONFIDENCE = 78%`).
3. **Классификация сырья:** определение фракции (`plastic`, `glass`, `paper`, `organic`, `mixed`).
4. **Определение размера контейнера:** `street`, `wheel` или `large`.

### 3.2. Математическая формула расчёта баллов (`calc_bin_points`):

Для урн (`category == "bin"`) итоговый балл выбирается из диапазона `[lo, hi]` в зависимости от уверенности нейросети (`confidence` от 0 до 100%):

$$\text{Points} = \begin{cases} 
hi & \text{если } \text{confidence} \ge 85\% \\ 
\min(lo + 1, hi) & \text{если } 78\% \le \text{confidence} < 85\% \\ 
lo & \text{если } \text{confidence} < 78\% 
\end{cases}$$

#### 🎯 Примеры начисления:
- Загружен большой контейнер (`large`, диапазон `[5, 6]`), уверенность нейросети `94%` $\rightarrow$ начисляется **6 коинов**.
- Загружена уличная урна (`street`, диапазон `[3, 4]`), уверенность нейросети `88%` $\rightarrow$ начисляется **4 коина**.
- Зафиксирована свалка отходов (`trash`, масштаб `massive`) $\rightarrow$ начисляется **8 коинов**.

## 4. 🛡️ Защита от накрутки (Anti-Fraud & Дедупликация)

Чтобы пользователи не могли многократно фотографировать один и тот же объект или спамить кликами:

1. **Дедупликация по ID запроса:**
   - Если один и тот же репорт отправлен клиентом повторно из-за повтора сети, сервер возвращает существующую запись без повторного начисления баллов.
2. **Дедупликация по фотографии (Image Hash / Media URL):**
   - Если за последние **10 минут** на сервер поступает репорт с тем же фото, он считается повторным кликом — баллы начисляются только 1 раз.
3. **Дедупликация по GPS-координатам:**
   - Если в радиусе тех же координат репорт был отправлен меньше **1 минуты** назад, создание дубликата блокируется.
4. **Атомарная транзакция в SQLite:**
   - Начисление баллов происходит на стороне бэкенда в единой транзакции базы данных:
     ```sql
     UPDATE profiles
     SET points = points + ?,
         bins_reported = bins_reported + 1,
         updated_at = datetime('now')
     WHERE username = ?;
     ```

## 5. 👮‍♂️ Модерация и списание баллов (Admin Moderation)

Администраторы сервиса контролируют достоверность добавляемых объектов через админ-панель:

1. **Удаление некорректной метки:**
   - Если администратор находит фейковый репорт, дубликат или несуществующую урну, он удаляет её с карты с указанием обязательной причины.
2. **Автоматический откат очков:**
   - Сервер моментально уменьшает баланс пользователя на сумму, полученную за этот репорт:
     $$\text{points} = \max(0, \text{points} - \text{report.points})$$
     $$\text{bins\_reported} = \max(0, \text{bins\_reported} - 1)$$
3. **Уведомление нарушителю:**
   - В раздел «Уведомления» нарушителя приходит системное оповещение:
     > *"Ваш отчёт «Большой контейнер» был удалён администратором. Списано 6 баллов. Причина: Неверные координаты."*

## 6. 🛍️ Где используются коины?

1. **Coin Shop:**
   - Обмен накопленных коинов на эксклюзивные промокоды, скидки в партнёрских кофейнях, магазинах эко-товаров и ресторанах.
2. **Лидерборд (Leaderboard):**
   - Рейтинг пользователей города формируется по общему числу заработанных коинов (`ORDER BY points DESC, bins_reported DESC`).
3. **Эко-статус:**
   - Рост рангов и достижений в профиле пользователя (Новичок $\rightarrow$ Эко-Активист $\rightarrow$ Хранитель города).
